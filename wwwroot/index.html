How to use this tool

What it does

Build and run Microsoft Search queries against the Graph POST /search/query API and read the exact request and response. It searches SharePoint, OneDrive and Copilot connectors from one place — something the classic SharePoint Search Query Tool cannot do.

Prerequisites

  • A Microsoft 365 work account that can read the content you want to query.
  • On first sign-in, an admin consents to three read-only scopes: Sites.Read.All, ExternalItem.Read.All, ExternalConnection.Read.All.
  • To query a Copilot connector, pick its connection from the dropdown (listed automatically once you sign in).

How it works

The tool runs on your machine and signs you in with your own delegated token. Every query is permission-trimmed to you, and no content leaves your tenant. Results come from the same Microsoft Search index that Copilot and the search box use.

How to use it

  1. Click the account circle (top-right) and sign in.
  2. Type a query.
  3. Choose a scope — all SharePoint sites, OneDrive, a specific site (search & pick), or a connector.
  4. Optionally set fields to return, a sort order, or facets to refine.
  5. Press Run query.
  6. Read the Results, or open Request / Response (raw) for the exact Graph call.

KQL tips

The query box accepts KQL. A few that work:

  • filetype:docx — restrict by file type
  • Path:"https://contoso.sharepoint.com/sites/HR" — restrict to a site
  • author:"Jane", title:policy — property restrictions
  • column* — prefix wildcard (no leading wildcard or *.* match-all)
  • sharepoint AND (list OR column) NOT archive — boolean operators

Property restrictions like Path: and filetype: apply to SharePoint and OneDrive, not connector items — those use their own connector schema properties.
